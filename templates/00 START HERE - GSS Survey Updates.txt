GSS SURVEY UPDATE
=================

1. Save rolling population workbooks in:
   02 Weekly Rolling Source Workbooks
2. Save guest-detail exports in:
   03 Uploaded Survey Workbooks
3. Close the main workbook in Excel.
4. Double-click Run GSS Update After Upload.cmd.
5. Read the result and Last GSS Result.txt.

Launching starts a normal validated update. No extra APPLY confirmation is
required. The program checks a staged copy and preserves the previous good
report before replacing it. Conflicting source corrections require a specific
choice. An undated guest-detail file may need its reporting week assigned.

Finished comparison PDFs are in 04 Email Comparison PDFs.

BACKUP PENDING means a backup needs retry. A Drive outage does not invalidate
a valid local report. If the local recovery snapshot failed, follow the recovery
message before another update. A Drive desktop copy check does not prove that
remote cloud upload has finished.

A population report with zero responses and blank scores is not currently
supported by the workbook model. The update stops and preserves the previous
good report instead of displaying misleading zero scores.

DRAFT PACKAGE BLOCKED means draft prerequisites are missing. It does not by
itself mean the workbook update failed. Packages contain personal guest data
and require recipient/content review. GSS never sends email automatically.
The report backup covers the original report snapshot. Detail added or corrected
later is saved in the draft package locally; LOCALONLY does not mean that later
draft evidence has an independent backup.

Run on only one computer at a time. Finish the previous run, close Excel, and
complete Dropbox synchronization before switching computers. Download cloud
files before reporting. The program requires Windows and Microsoft Excel.

If a run is interrupted, preserve its files and follow the specific recovery
message. Do not delete a transaction marker to force another update.

Setup and recovery instructions:
GSS Survey Workbook Automation\docs\operations.md

Use the main workbook and source/report folders for everyday work. Logs, tests,
backups, state, and packages are internal files under _automation_runs.
Scheduled reporting and automatic email sending remain disabled.
